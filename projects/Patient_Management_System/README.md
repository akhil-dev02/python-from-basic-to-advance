# Patient Management System - Separate CRUD Modules

This project keeps Register, Update and Delete operations in separate Python modules.

## Files

- main.py -> Main application
- patient_data.py -> Shared patient data
- register_patient.py -> Register Patient
- view_patient.py -> View and Search Patient
- update_patient.py -> Update Patient
- delete_patient.py -> Delete Patient
- utils.py -> Common utility functions

## Menu

1. Register Patient
2. View Patients
3. Search Patient
4. Update Patient
5. Delete Patient
0. Exit

## Run

Open this folder in VS Code and run:

python main.py

## Important

This version uses Python lists for data storage.
Data is available while the program is running.
When the program closes, the data is reset.
